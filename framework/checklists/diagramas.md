# Checklist de diagramas

| Verificação | Evidência esperada |
|---|---|
| Tipo, legenda, versão e fonte do diagrama identificados | Figura controlada |
| Limites, interfaces, fluxos e símbolos são inteligíveis | Inspeção visual |
| Texto e linhas são legíveis no meio de distribuição | Renderização/arquivo fonte |
| Diagrama não é tratado como especificação não escrita | Referência cruzada |
