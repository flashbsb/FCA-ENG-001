# Checklist ISO

| Verificação | Evidência esperada |
|---|---|
| Norma, edição e cláusula são identificadas | Catálogo |
| Aplicabilidade e obrigação têm autoridade documentada | Contrato/regulação/política |
| Certificação organizacional não é confundida com aderência de requisito | Evidência distinta |
| A conclusão respeita escopo e método de avaliação | Plano/achado |
