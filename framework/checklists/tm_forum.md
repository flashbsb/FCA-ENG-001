# Checklist TM Forum

| Verificação | Evidência esperada |
|---|---|
| Referência a Open API, SID ou eTOM inclui versão e aplicabilidade | Catálogo/cláusula |
| “Conforme TM Forum” é decomposto em capacidade verificável | API/processo/modelo |
| Certificação é distinguida de compatibilidade declarada | Evidência do fornecedor |
| Não se impõe TM Forum sem decisão de escopo | Autoridade/premissa |
