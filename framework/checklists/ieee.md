# Checklist IEEE

| Verificação | Evidência esperada |
|---|---|
| Padrão e edição são identificados | Catálogo |
| Perfil técnico aplicável é especificado | Requisito/desenho |
| Conformidade não é presumida por nomenclatura comercial | Evidência/teste |
| Exceções e interoperação são tratadas | Matriz de compatibilidade |
