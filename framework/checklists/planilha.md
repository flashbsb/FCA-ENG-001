# Checklist de Análise de Planilhas (.xlsx, .csv)

| Verificação | Evidência Esperada | Destino do Registro |
|-------------|-------------------|---------------------|
| Todas as abas da planilha têm nome e propósito identificável | Nome da aba autoexplicativo | `index.html #fichas` |
| Cabeçalhos de coluna presentes e com unidade de medida definida | Cabeçalho + unidade | `index.html #fichas` |
| Células obrigatórias sem dados ausentes identificadas | Linhas com dados incompletos | `index.html #fichas` |
| Totalizadores conferem com a soma dos itens | Verificação aritmética | `index.html #fichas` |
| Itens duplicados com valores divergentes identificados | Comparação de linhas | `index.html #fichas` |
| Quantitativos da planilha consistentes com especificação técnica | Comparação 1:1 | `index.html #fichas` |
| Modelos/itens da planilha correspondentes aos descritos no documento | Correlação cruzada | `index.html #fichas` |
| Unidades consistentes entre planilha e documentos (ex: GB vs TB) | Unidades verificadas | `index.html #fichas` |
| Prazos e cronogramas da planilha consistentes com texto | Comparação de datas | `index.html #lacunas-riscos` |
| Planilha cobre todos os itens declarados nos documentos textuais | Cobertura completa | `index.html #lacunas-riscos` |
| Preços de referência têm fonte ou data de vigência indicada | Referência de mercado | `index.html #lacunas-riscos` |
