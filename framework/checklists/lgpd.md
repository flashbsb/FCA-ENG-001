# Checklist de Conformidade com LGPD (Lei 13.709/2018)

| Verificação | Evidência Esperada | Destino do Registro |
|-------------|-------------------|---------------------|
| Finalidade do tratamento de dados pessoais declarada | Cláusula ou seção explícita | `index.html #fichas` |
| Base legal do tratamento identificada (Art. 7º ou Art. 11) | Texto da base legal | `index.html #fichas` |
| Princípio da minimização: dados limitados ao mínimo necessário | Justificativa de necessidade | `index.html #fichas` |
| Mecanismo de atendimento a direitos dos titulares previsto | Canal/prazo definido | `index.html #lacunas-riscos` |
| Prazo de retenção e descarte de dados definido | Prazo explícito | `index.html #lacunas-riscos` |
| Criptografia em trânsito e em repouso para dados sensíveis | Especificação técnica | `index.html #fichas` |
| Controles de acesso a dados pessoais especificados | RBAC, IAM ou equivalente | `index.html #fichas` |
| Procedimento de notificação de incidente à ANPD | Prazo e responsável definidos | `index.html #lacunas-riscos` |
| Cláusula de proteção de dados no contrato com operador | Cláusula verificável | `index.html #fichas` |
| Operador proibido de usar dados para fins próprios | Vedação explícita | `index.html #fichas` |
| Transferência internacional de dados: base legal identificada | Art. 33 LGPD citado | `index.html #fichas` |
| RIPD previsto para tratamentos de alto risco | Referência ao RIPD | `index.html #lacunas-riscos` |
| Registro de atividades de tratamento (ROPA) previsto | Artefato ou cláusula | `index.html #checklists` |
