# Checklist de imagens e diagramas

| Verificação | Evidência esperada |
|---|---|
| Nome do arquivo obedece à convenção `fig{NN}_{doc}_{secao/pag}_{descricao}.png` | Nomenclatura |
| Resolução e legibilidade de rótulos, portas e interfaces no formato de entrega | Renderização visual / OCR |
| Imagem possui hash SHA-256 e referência exata de seção/página registrada na baseline | Inventário de baseline |
| Componentes e topologias visuais são coerentes com as exigências do texto | Confronto imagem x texto |
| Ausência de conflitos arquiteturais (ex: quantidade de dispositivos, enlaces de redundância) | Análise de consistência |
| Informação crítica visual possui equivalente descritivo ou acoplamento rastreável | Rastreabilidade / Acessibilidade |
| Imagem não contém dado sensível indevido ou marca comercial sem neutralidade | Classificação / Compliance |
