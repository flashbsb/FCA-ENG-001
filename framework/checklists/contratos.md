# Checklist de contratos

| Verificação | Evidência esperada |
|---|---|
| Escopo, entregáveis, aceite e mudança são objetivos | Cláusula/anexo |
| Riscos, responsabilidades e dependências são atribuídos | Matriz/cláusula |
| Revisor não interpreta juridicamente nem redige ato vinculante | Encaminhamento jurídico |
| Lacunas contratuais são encaminhadas como pergunta/recomendação | Registro rastreável |
