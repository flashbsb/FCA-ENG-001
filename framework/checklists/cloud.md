# Checklist cloud

| Verificação | Evidência esperada |
|---|---|
| Modelo de responsabilidade compartilhada está declarado | Contrato/arquitetura |
| Região, residência de dados, continuidade e portabilidade são tratadas | Requisitos verificáveis |
| Identidade, rede, observabilidade e custos têm fronteiras | Desenho e operação |
| Serviços gerenciados não são assumidos sem evidência | Catálogo/fonte |
