# Checklist de tabelas

| Verificação | Evidência esperada |
|---|---|
| Título, fonte, unidades e versão são claros | Tabela controlada |
| Cabeçalhos, notas e chaves de leitura são completos | Inspeção |
| Valores e totais têm origem ou premissa declarada | Fonte verificável |
| Tabela não mascara texto normativo ou exceções relevantes | Leitura cruzada |
