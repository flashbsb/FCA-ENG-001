# Checklist RFC

| Verificação | Evidência esperada |
|---|---|
| RFC é identificada por número, título e status | Fonte IETF |
| Termos MUST/SHOULD são usados no contexto da RFC, não traduzidos automaticamente | Trecho/escopo |
| Protocolo, versão e perfil são identificados | Requisito/interface |
| Conformidade é validada por teste ou evidência apropriada | Relatório de teste |
