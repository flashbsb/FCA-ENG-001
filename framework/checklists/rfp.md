# Checklist de Análise de RFP / RFI / Edital

| Verificação | Evidência Esperada | Destino do Registro |
|-------------|-------------------|---------------------|
| Todos os documentos referenciados no texto estão presentes no lote | Lista de arquivos do lote | `index.html #lacunas-riscos` |
| Objeto da contratação claramente definido e mensurável | Texto do objeto | `index.html #fichas` |
| Critérios de aceite de cada entregável definidos | Critérios verificáveis | `index.html #fichas` |
| Requisitos funcionais com critério de aceite verificável | Critério por requisito | `index.html #fichas` |
| Requisitos não funcionais quantificados (SLA, capacidade, desempenho) | Valores numéricos | `index.html #lacunas-riscos` |
| Verbos normativos usados de forma consistente (DEVE, DEVERIA, PODE) | Mapeamento de verbos | `index.html #fichas` |
| Ausência de requisitos vagos sem definição técnica | Termos vagos mapeados | `index.html #fichas` |
| SLAs têm: valor, janela de medição, método, penalidade | Tabela de SLAs completa | `index.html #fichas` |
| SLAs consistentes entre documento principal e anexos | Comparação direta | `index.html #fichas` |
| Normas referenciadas com edição especificada | Norma + edição + status | `index.html #fichas` |
| Cláusulas de rescisão com prazo e ressarcimento definidos | Cláusula verificável | `index.html #lacunas-riscos` |
| Penalidades proporcionais e com processo de glosa definido | Processo descrito | `index.html #lacunas-riscos` |
| Consistência entre planilha de quantitativos e especificação técnica | Comparação linha a linha | `index.html #fichas` |
| Prazo de entrega coerente com o escopo técnico declarado | Justificativa de prazo | `index.html #fichas` |
| Responsabilidades (Contratante × Contratada) claramente segregadas | Matriz de responsabilidades | `index.html #lacunas-riscos` |
